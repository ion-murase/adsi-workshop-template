# Unit of Work 分割 — 勤怠管理アプリ

## 分割方針

- 2人で並行実装可能な形に分割
- 共通基盤（Unit 0）を最初に完成させ、以降の Unit はそれに依存する
- Phase B の Unit 群は互いに独立しており、2人で分担可能

---

## Phase 割り当て

| Phase | Unit | 担当 | 前提 |
|-------|------|------|------|
| A | Unit 0: 共通基盤 | 2人共同 | なし |
| B | Unit 1: 組織・認証 | 担当者A | Unit 0 |
| B | Unit 2: 打刻・勤務時間 | 担当者B | Unit 0 |
| B | Unit 3: 通知基盤 | 担当者A or B（小さい） | Unit 0 |
| C | Unit 4: 申請・承認 | 担当者A | Unit 1, 2, 3 |
| C | Unit 5: 有給・集計・CSV | 担当者B | Unit 1, 2, 4 |

---

## 並行実装の進め方

```
Week 1:  [Unit 0 共通基盤] ← 2人共同
         ─────────────────────────────────────
Week 2:  担当A: [Unit 1 組織・認証]    担当B: [Unit 2 打刻]
         担当A: [Unit 3 通知（小）]
         ─────────────────────────────────────
Week 3:  担当A: [Unit 4 申請・承認]    担当B: [Unit 5 有給・集計・CSV]
         ─────────────────────────────────────
Week 4:  統合テスト・E2E
```
