# 画面設計

## 画面一覧

| # | 画面名 | パス | ロール | 説明 |
|---|--------|------|--------|------|
| 1 | ログイン | /login | 全員 | メール/パスワード入力 |
| 2 | パスワード変更 | /change-password | 全員 | 初回/任意のパスワード変更 |
| 3 | ダッシュボード（打刻） | / | 全員 | 出勤/退勤/外出/戻りボタン、本日の勤務状態 |
| 4 | 勤務履歴 | /time-records | 全員 | 月別一覧テーブル + 月次集計サマリ |
| 5 | 申請一覧 | /applications | 全員 | 自分の申請一覧（状態フィルタ） |
| 6 | 打刻修正申請 | /applications/clock-fix/new | 全員 | 修正対象日・時刻・理由入力フォーム |
| 7 | 有給休暇申請 | /applications/leave/new | 全員 | 休暇日・種別選択フォーム |
| 8 | 承認待ち一覧 | /approvals | 承認者 | 部下の申請一覧、承認/却下アクション |
| 9 | 通知一覧 | /notifications | 全員 | 通知リスト（未読/既読フィルタ） |
| 10 | ユーザ管理 | /admin/users | 管理者 | ユーザCRUD一覧 |
| 11 | ユーザ登録/編集 | /admin/users/new, /admin/users/:id | 管理者 | ユーザ情報入力フォーム |
| 12 | 部署管理 | /admin/departments | 管理者 | 部署CRUD一覧 |
| 13 | 拠点管理 | /admin/sites | 管理者 | 拠点CRUD一覧 |
| 14 | 会社カレンダー | /admin/calendar | 管理者 | 年度別休日一覧 + 追加/削除 |
| 15 | CSVエクスポート | /export | 全員 | 対象データ・期間選択 → ダウンロード |

## 画面遷移図

```
[ログイン] ─→ [パスワード変更]（初回のみ）
    │
    ▼
[ダッシュボード（打刻）] ← ヘッダーナビ共通 →
    │
    ├─ [勤務履歴]
    ├─ [申請一覧] ─→ [打刻修正申請] / [有給休暇申請]
    ├─ [承認待ち一覧]（承認者のみ）
    ├─ [通知一覧]
    ├─ [CSVエクスポート]
    └─ [管理]（管理者のみ）
         ├─ [ユーザ管理] ─→ [ユーザ登録/編集]
         ├─ [部署管理]
         ├─ [拠点管理]
         └─ [会社カレンダー]
```

## 共通コンポーネント

| コンポーネント | 説明 |
|---------------|------|
| Header | ロゴ、ナビゲーション、通知バッジ、ユーザメニュー |
| Sidebar | ナビゲーションメニュー（モバイルではハンバーガー） |
| NotificationBadge | 未読通知件数表示 |
| DataTable | ソート・ページネーション付きテーブル |
| MonthPicker | 年月選択コンポーネント |
| ConfirmDialog | 確認ダイアログ（承認/却下/削除等） |
| Toast | 操作結果のフィードバック通知 |
| FormField | ラベル + 入力 + バリデーションメッセージ |
| StatusBadge | 申請ステータスの色付きバッジ |
| LoadingSpinner | ローディング表示 |
| EmptyState | データがない場合の案内表示 |
| ErrorBoundary | エラー時のフォールバックUI |

## レスポンシブ対応方針

| ブレークポイント | レイアウト |
|----------------|-----------|
| < 768px (mobile) | ハンバーガーメニュー、1カラム、テーブルはカード化 |
| 768px - 1024px (tablet) | サイドバー折りたたみ、2カラム |
| > 1024px (desktop) | サイドバー展開、フルテーブル表示 |

## 技術スタック（Frontend）

| 項目 | 選定 |
|------|------|
| フレームワーク | Next.js (App Router) |
| 言語 | TypeScript |
| スタイリング | Tailwind CSS |
| UIライブラリ | shadcn/ui |
| 状態管理 | TanStack Query (サーバステート) |
| フォーム | React Hook Form + Zod |
| テスト | Vitest + Testing Library |
| API通信 | fetch wrapper with basePath対応 |
